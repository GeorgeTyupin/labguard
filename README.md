# FileGuard

Платформа лицензирования и защиты интеллектуальной собственности с автоматической проверкой доступа через десктопный клиент. Универсальное решение для безопасной дистрибуции продуктов и удаленной защиты коммерческих и частных проектов.

## О продукте

FileGuard решает задачу безопасного распространения, лицензирования и защиты программных проектов и других цифровых продуктов. Пользователи приобретают доступ через Telegram-бота и получают персональную лицензию, которая верифицируется специальным клиентом непосредственно перед запуском защищаемого проекта.

**Ключевые возможности:**
- Покупка и управление лицензиями через удобный Telegram-интерфейс
- Надежная защита от несанкционированного копирования через fingerprint устройства
- Автоматическая проверка прав доступа при локальном запуске проектов
- Централизованная система управления выданными лицензиями

## Архитектура

Система состоит из трёх компонентов:

```text
┌─────────────┐      ┌──────────────┐      ┌─────────────┐
│ Telegram    │─────▶│ HTTP Server  │◀─────│   Client    │
│    Bot      │      │     API      │      │ (fileguard  │
│             │      │              │      │    .exe)    │
└─────────────┘      └──────┬───────┘      └─────────────┘
     │                      │                      │
     │                      ▼                      │
     │               ┌──────────────┐              │
     └──────────────▶│  PostgreSQL  │◀─────────────┘
                     └──────────────┘
```

### 1. Telegram Bot
Пользовательский интерфейс платформы. Включает регистрацию, просмотр каталога продуктов и оформление покупок.

**Команды:**
- `/start` — регистрация в системе и получение токена доступа
- `/catalog` — просмотр доступных проектов и лицензий
- `/my` — личный кабинет со списком приобретённых продуктов

**Стек:** telebot.v4, Go 1.25

### 2. HTTP Server
REST API для взаимодействия Telegram-бота и десктопного клиента с базой данных.

**Эндпоинты:**
- `POST /api/v1/users` — регистрация нового пользователя
- `POST /api/v1/verify` — аппаратная проверка валидности лицензии
- `GET /api/v1/products` — выдача каталога проектов

**Стек:** Chi router, PostgreSQL (pgx)

### 3. Desktop Client
Облегченный клиент, обеспечивающий проверку лицензии перед локальным запуском защищаемого проекта.

**Логика работы:**
1. Читает авторизационный токен из `fileguard.key`
2. Генерирует уникальный аппаратный отпечаток (fingerprint) устройства
3. Отправляет данные для сервера верификации
4. Возвращает Exit code: `0` = доступ разрешён, `1` = в доступе отказано

## Архитектурные принципы

- **Clean Architecture** — строгое разделение слоев: handler → service → repository
- **Dependency Injection** — внедрение зависимостей через конструкторы
- **Consumer-side interfaces** — идиоматичный подход к проектированию в Go
- **Graceful shutdown** — безопасное и корректное завершение работы сервисов

## Roadmap

### Ближайшее развитие

**Платёжная интеграция**
- Интеграция с агрегаторами платежей (ЮKassa/Robokassa)
- Автоматический процессинг и подтверждение транзакций
- Webhook уведомления статусов платежей

**Защита цифровых продуктов**
- Продвинутая реализация fingerprint защиты с привязкой к множеству аппаратных метрик
- Механизм контролируемого сброса привязки (например, 1 раз в 30 дней)
- Улучшенная защита от несанкционированного клонирования на другой ПК

**База данных и надежность**
- Внедрение системы миграций (golang-migrate)
- Расширение схемы БД для глубокой аналитики (users, products, purchases, devices)
- Гарантированная транзакционность при создании лицензий

### Перспективные возможности

**Панель администратора**
- Удобное управление каталогом доступных продуктов
- Подробная аналитика продаж и использования проектов
- Инструменты управления клиентской базой
- Ручная модерация и управление проблемными транзакциями

**Интеграция с системами контроля версий**
- Автоматическая выдача доступов к закрытым репозиториям GitHub/GitLab
- Синхронизация ролей и прав через API платформ
- Мгновенный отзыв прав доступа при истечении лицензии

**Эволюция десктопного клиента**
- Прозрачное автообновление клиентской части
- Поддержка безопасного Offline-режима (криптографически подписанные временные лицензии)
- Расширенная телеметрия для выявления попыток взлома

**Масштабирование бизнес-модели**
- Поддержка гибких ролевых подписок (SaaS модель)
- Корпоративные и групповые лицензии (B2B сегмент)
- Система промокодов, скидок и региональных цен
- Партнерская и реферальная программа

## Развертывание и запуск

```bash
# Telegram бот
go run cmd/bot/main.go

# HTTP API сервер
go run cmd/server/main.go
```
